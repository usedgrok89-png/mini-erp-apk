# مدير المنتجات — تطبيق أندرويد محلي

تطبيق أندرويد صغير وشكل عربي أنيق، يعمل **بدون إنترنت أو سيرفر**، ويتكيف مع أي مشروع تصنيفي صغير.

## الفكرة والمنطق
- **المكونات:** أسعار المكونات لكل جرام — **للعلم فقط**، لا تُستخدم في تحديد سعر البيع.
- **التركيبات:** المكونات بجراماتها + خطوات التصنيع، مع رقم تكلفة استرشادي للعلم.
- **المنتجات:** كل منتج له أحجام، و**لكل حجم سعر يضعه المستخدم يدويًا**.
- **المبيعات:** تختار المنتج والحجم → السعر يُملأ تلقائيًا من المحفوظ → الكمية → الخصم (نسبة أو مبلغ) → إجمالي الفاتورة.
- **الفواتير:** حفظ + نسخة PDF بخط عربي واتجاه RTL، مع تثبيت الأسعار وقت البيع حتى لا تتغير الفواتير القديمة عند تعديل الأسعار.
- **بحث** فوري في كل صفحات البيانات (المكونات، التركيبات، المنتجات، المبيعات، الفواتير).
- **تنبيه تكرار**: لو الاسم موجود، التطبيق يقترح تعديل الموجود بدل إضافة نسخة.
- **وضع نهاري/ليلي** (أو تبع نظام الجهاز) من الإعدادات، مع تلوين شريط النظام.
- **نسخة احتياطية JSON** كاملة (تصدير/استيراد) من الإعدادات.
- **شكل عصري**: رؤوس بتدرج لوني، كروت وأزرار دائرية الأطراف.
- **الإعدادات:** العملة، اسم المحل وبياناته، ملاحظة الفاتورة.

## المميزات التقنية
- Kotlin + Jetpack Compose (Material 3)، اتجاه RTL مفروض على كل الشاشات.
- خط عربي مدمج **Tajawal** (Regular + Bold — ~120KB فقط).
- قاعدة بيانات **SQLite** المدمجة في أندرويد مباشرة (بدون Room) → تبعيات أقل وحجم أصغر.
- توليد PDF بـ `PdfDocument` المدمج في أندرويد — **مكتبات صفرية**.
- البيانات كلها محفوظة داخل الجهاز (`filesDir/minierp.db`)، والـ PDF في `filesDir/documents/invoices`.
- تصغير الكود (R8) مُفعّل في نسخة Release.

## طريقة التشغيل

### من التلفون عبر Termux (بدون كمبيوتر) ← الأفضل لك
اتبع الخطوات في **[TERMUX.md](TERMUX.md)**: ارفع المشروع على GitHub، وGitHub Actions يبني APK، وتنزّله وتثبّته من Termux.

### من الكمبيوتر (اختياري)
1. افتح مجلد المشروع في **Android Studio** (إصدار حديث يدعم AGP 8.7 و Kotlin 2.0).
2. انتظر مزامنة Gradle (سيُنزّل التبعيات من Google Maven تلقائيًا).
3. شغّل التطبيق على جهاز أو محاكي (Android 6.0 / API 23 فأعلى).

> Gradle wrapper مرفق بالمشروع (Gradle 8.9)، والبناء السحابي جاهز في `.github/workflows/build-apk.yml`.

## الحجم المتوقع
APK النسخة Release حوالي **5–8 ميجابايت** (Compose + الخط). يمكن تقليله أكثر بإزالة أي تبعيات غير مستخدمة أو باستخدام App Bundle.

## أفكار للتطوير لاحقًا
- تصدير/استيراد نسخة احتياطية JSON (مهم لتطبيق محلي بالكامل).
- طباعة مباشرة عبر طابعة Bluetooth/USB بدل مشاركة الملف.
- إضافة صور للمنتجات (محفوظة محليًا).
- دعم أكثر من لغة مع الحفاظ على العربية كأساس.
